Secure Code Improvements
Improvement 1: Removed Password Display

The application no longer displays the user's password on the screen.

Benefit:

Prevents accidental exposure of sensitive information.
Improvement 2: Generic Authentication Message

The application uses a generic error message.

Benefit:

Avoids revealing unnecessary information during authentication.
Improvement 3: Better Handling of User Information

Only non-sensitive information is displayed.

Benefit:

Reduces the risk of exposing confidential data.
